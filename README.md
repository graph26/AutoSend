# AutoSend

This program is necessary for automating Telegram channels.

## 🚀 Features
- Feature 1: The ability to send different messages to a channel at different times (frequency, specific date, now).
- Feature 2: This product has all the necessary features to get started.
- Feature 3: Beautiful design and clear interface.

## 🛠️ Built With
- Python 3.13.5
- PyQt5
- Pyrogram
- pydantic, typing
